# One line per test: name, the configurations it applies to (comma-separated,
# no spaces, or * for all), then the reason. run-arch-tests.sh still runs a
# waived test: a failure is reported as WAIVED and kept out of the verdict, and
# a pass fails the run until the line is removed, so a waiver cannot outlive

PMPSm_cfg_A_tor_zero-00  *  Stores, loads and executes at address 0, where the testbench maps its AXI error slave. ACT assumes memory there regardless of the declared memory map, and Sail treats undeclared address 0 as memory. The probe cannot catch a PMP bug: entry 0 and the background entry are both locked RWX, so it only checks that memory exists at 0.
Sm_mcsr_access-00  cv64a6_imafdchsclic_sv39_wb,cv64a6_imafdchsclic_sv39_hpdcache_wb,cv64a6_imafdchxhclic_sv39_wb,cv64a6_imafdchxhclic_sv39_hpdcache_wb  The core implements the CLIC mtvec mode (mtvec[1:0] = 3), which UDB cannot express, so mtvec[1] reads back set where MTVEC_MODES [0, 1] requires zero. The test stops at that check, so its later CSR checks do not run on CLIC configurations.
